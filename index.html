About

Project objective

Sortify helps students understand how sorting algorithms work by showing each comparison and swap as it happens, with live statistics and a step-by-step learning mode.

Learning outcomes

  • Explain how Bubble, Selection, Insertion, Merge, Quick and Heap Sort work.
  • Compare algorithms by time complexity, space, stability and in-place behaviour.
  • See how input order (random, nearly sorted, reversed, duplicates) changes the work an algorithm does.

Technologies used

HTML5, CSS3 and vanilla JavaScript. No backend, no database, no framework. The algorithms record their real operations, and the interface replays them.
